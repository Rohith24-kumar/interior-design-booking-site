    
# Nordic Designs – Interior Design Website 🌿

A modern, responsive multi-page website for an interior design studio inspired by Scandinavian (Nordic) aesthetics.
Built using pure **HTML, CSS, and JavaScript** with smooth animations, clean layouts, and mobile-friendly design.

---

## 🚀 Live Preview
> Run locally using a simple server (recommended) or open `index.html` directly in your browser.

```bash
# Option 1 (Python)
python3 -m http.server 5050

# Option 2 (Node)
npx serve .

```

Then open:
👉 [http://localhost:5050](http://localhost:5050)

## ✨ Features
- 🎨 Scandinavian-inspired UI design

- 📱 Fully responsive (mobile, tablet, desktop)

- 🧭 Smooth navigation with hamburger menu

- 🖼️ Animated hero section & scroll animations

- 🧩 Portfolio filtering system

- 📝 Contact form UI (ready for backend integration)

- ⚡ Fast loading and lightweight

- 🌗 Supports modern UI effects and transitions

## 🛠️ Tech Stack
